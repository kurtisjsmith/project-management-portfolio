# Project Adoption Register

This document tracks publicly available projects using the Project Management Framework.

The register is updated as individual repositories are approved for public release and their management-standard adoption status is verified.

## Publication and Adoption

Repository publication and framework adoption are independent.

A project may be public without having completed adoption of the framework. Likewise, a private project may already be fully aligned with an approved version of the Master Project Management Standard.

## Adoption Classifications

| Classification              | Meaning                                                                                     |
| --------------------------- | ------------------------------------------------------------------------------------------- |
| Established Under Framework | A project initiated using an approved version of the framework                              |
| Adoption In Progress        | An existing project progressively aligning with the framework                               |
| Aligned                     | The project's adoption requirements have been verified against a specified standard version |
| Not Yet Assessed            | Framework adoption has not been evaluated                                                   |

Classifications describe documented management practices, not application-development maturity or software quality.

Projects are added only after publication authorization and verification of their publicly accessible repositories.

## Verification Requirements

Before adding or updating an entry:

1. Confirm that the repository is publicly accessible.
2. Verify its project identity and repository link.
3. Identify the applicable Master Standard version.
4. Review evidence supporting the adoption classification.
5. Obtain Project Owner approval for the public entry.

## Maintenance

The private authoritative Project Management repository retains internal adoption decisions and verification records.

This public register is updated from approved information. A revision to the Master Standard does not automatically change an existing project's verified adoption status.

Entries may be revised when new evidence supports a change, with the update preserved in the public repository's Git history.
